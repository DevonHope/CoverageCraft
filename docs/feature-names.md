# Name checks

The Craft naming standard asks for a check of every product and feature name, and says "unclear
means no". This file records what was checked, when and how far.

## The app's name

Checked 2026-11-22 with web searches, GitHub repository search and crates.io, then on 2026-11-23
in the trademark registers: USPTO Trademark Search, the WIPO Global Brand Database (90 sources,
among them the US, EU, Canadian, Australian and Japanese registers) and the Canadian Trademarks
Database.

| Name | Result | Why |
|---|---|---|
| NetCraft | **No** | NETCRAFT is a live US trademark of Netcraft Ltd for software and internet services (classes 9 and 42). |
| SignalCraft | No | Already the name of a software product. |
| RangeCraft | No | A live trademark filing. |
| WaveCraft | No | A company name in software. |
| RadioCraft | **No** (register search, 2026-11-23) | Live marks in the same field. RADIOCRAFT is registered in Canada (TMA821378, application 1521688; to 2027-04-03) for radio transceivers, receivers, transmitters, scanners and antennas (class 9) and their repair (class 37). RADIOCRAFTS, LumenRadio AB's (who make the Radiocrafts RF modules), is registered in the EU (019046435), the US (8208679), Japan, Brazil and Australia and pending in Canada, through international registration 1830303, for wireless communication apparatus and radio modules for building automation (class 9) and lighting (class 11). The other US RADIOCRAFT and RADIO CRAFT marks (radio broadcasting; an electronics magazine) are dead. Also used by GitHub projects (an ARRL-funded Minecraft radio mod; a Rust radio-automation rebuild). |
| CoverageCraft | Clear (register search, 2026-11-23) | No marks in the WIPO Global Brand Database; no GitHub repositories or crates; no web hits. |
| AirwaveCraft | Clear (register search, 2026-11-23) | No marks in the WIPO Global Brand Database; no GitHub repositories or crates; no web hits. |
